# Promise-checking memory house

Authorized scope: more amendment practice, constitutional checks on fictional campaign promises, bookmarks and private browser progress, retrieval reinforcement, meaningful crayon art, mnemonic stories, official exam resources. The same standards apply to every political side and age group. No political preference earns points.

Implementation: sixteen questions appended to the existing bank; `/civic/` uses the existing Quiz, progress scheduler and marks provider. Four story rooms explain amendment gates, bounded electoral authority, protected participation and public-spending authority. A resume cookie records only a fixed room ID. Detailed progress stays in local browser storage and the existing version-4 backup. Library, amendment journey and Notes link to the new path.

Preserved: all original questions, bookmarks, highlights, reading history, legal corpus, translations, news, diagrams, knowledge map and four themes. No file collapsed. No account or new data collection. Shared browsers share the notebook, explicitly disclosed.

Review questions: first-reading at-least-half vs final more-than-half; all eligible-party MP gates; not every amendment requires referendum; no campaign promise independently authorises spending; peaceful unarmed assembly is protected subject to lawful restrictions; ordinary bills and amendment petitions have different signature routes. Whole replacement is outside the simulator’s scope. Original practice is never labelled official/past exam questions.
