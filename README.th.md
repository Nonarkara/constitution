## 🎨 แนวคิดการออกแบบ: สุนทรียศาสตร์แบบ Civic & ภาพวาดดินสอสี (Crayon Aesthetic)

แอปพลิเคชันนี้ออกแบบมาเพื่อเปลี่ยนการศึกษากฎหมายที่แห้งแล้งและน่ากลัว ให้กลายเป็น **"สมุดบันทึกที่อบอุ่นและมีชีวิต"**:
- **กระดาษขาวสะอาดตา & เส้นหมึกคมชัด:** ตัวอักษรใช้ฟอนต์ `IBM Plex Sans Thai`, `Source Sans 3` และ `JetBrains Mono` ไม่ใช้เงา ไม่ใช้การไล่ระดับสีที่รบกวนสมาธิ
- **สีเหลืองอำพัน (Amber `#f59e0b`):** เป็นสีเน้นหลักเพียงหนึ่งเดียว แสดงปุ่มการกระทำถัดไปและจุดที่กำลังโฟกัส
- **ภาพวาดดินสอสีขี้ผึ้ง (Wax-Crayon Artwork):** ภาพวาดประกอบฉากการอ่าน ฟัง และทบทวน ลายเส้นดินสอสีขี้ผึ้งที่ดูเป็นมิตร อบอุ่น มีตัวละครเสื้อสเวตเตอร์สีอำพันเรียนรู้อย่างสบายใจ
- **แผนภาพและตราชั่งสไตล์ Crayon:** แผนผังลำดับศักดิ์กฎหมาย, ขั้นตอน 3 วาระแก้ รธน., ตราชั่งความได้สัดส่วน และแผนผังการออก พ.ร.ก. วาดด้วยสไตล์ลายเส้นดินสอสีที่ไม่แข็งกระด้าง

## 🧭 ลำดับขั้นตอนการเรียนรู้ที่มีประสิทธิภาพ (Learning Steps)

ระบบเรียนรู้ของแอปพลิเคชันถูกออกแบบตามหลักวิทยาศาสตร์การรู้คิด (Cognitive Science) 6 ขั้นตอน:

```
[ขั้น 1: ปริศนาชีวิตจริง] ──> [ขั้น 2: อ่านตัวบทแท้] ──> [ขั้น 3: สรุปสูตรอัลกอริทึม]
    (เดาก่อนเพื่อกระตุ้น)       (เทียบ 3 ภาษา + ฟัง)       (แผนภาพดินสอสีในสมุด)
            │
            ▼
[ขั้น 4: ฝึกตอบสถานการณ์] ──> [ขั้น 5: ทบทวนเว้นระยะ] ──> [ขั้น 6: ท่องจำด้วยเรื่องเล่า]
   (85 ข้อสอบ 17 หมวด)        (Spaced Repetition)         (Mnemonics & Rhymes)
```

1. **ขั้นที่ 1: ปริศนาชีวิตจริงก่อนอ่าน (Life-First Puzzle):** เริ่มต้นแต่ละหมวดด้วยคดีใกล้ตัว (เช่น สิทธิความเป็นส่วนตัวในโทรศัพท์, การตรวจค้น, สิทธิผู้บริโภค) ให้ผู้เรียน "เดาก่อนอ่าน" เพื่อกระตุ้นสมองส่วนความจำ
2. **ขั้นที่ 2: อ่านตัวบทจริงเสมอ (Verbatim Legal Text):** อ่านตัวบทภาษาไทยจากราชกิจจานุเบกษา พร้อมคำแปลเทียบเคียงภาษาอังกฤษและภาษาจีน มีระบบเสียงอ่าน 837 มาตรา และลิงก์เสียงวุฒิสภา
3. **ขั้นที่ 3: ถอดรหัสด้วยอัลกอริทึม (Algorithmic Logic Gates):** แปลงกระบวนการทางกฎหมายที่ซับซ้อนให้กลายเป็น "ตรรกะแบบโปรแกรม" (เช่น ม.5 ขัด รธน. = โมฆะ, ม.256 เงื่อนไขล็อก 3 ชั้น)
4. **ขั้นที่ 4: ฝึกดึงความจำ (Deliberate Practice):** คลังข้อสอบ 85 ข้อ (ครอบคลุมทั้ง 16 หมวด + บทเฉพาะกาล หมวดละ 5 ข้อ) มีคำเฉลยอ้างอิงมาตราและสูตรวิเคราะห์
5. **ขั้นที่ 5: ทบทวนตามระยะเวลาลืม (Spaced Repetition):** ข้อที่ตอบผิดจะกลับมาซ้ำใน 10 นาที; ข้อที่ตอบถูกจะเว้นระยะเป็น 1 วัน, 3 วัน, 7 วัน และ 14 วัน
6. **ขั้นที่ 6: สูตรจำและคำกลอน (Mnemonics & Stories):** ใช้เรื่องเล่าเปรียบเทียบและกลอนสัมผัสคล้องจองช่วยล็อกตัวเลขสำคัญไม่ให้ลืมในห้องสอบ

## ⚡ สรุปสูตรอัลกอริทึมกฎหมายรัฐธรรมนูญ (Cheat Sheets)

### 1. ลำดับศักดิ์ของกฎหมาย (มาตรา 5)
```
                  ┌────────────────────────┐
                  │ 1. รัฐธรรมนูญ (ม.5)    │ กฎหมายสูงสุด
                  └───────────┬────────────┘
                              │
                  ┌───────────▼────────────┐
                  │ 2. พ.ร.ป. / พ.ร.บ./ พ.ร.ก.│ กฎหมายระดับพระราชบัญญัติ
                  └───────────┬────────────┘
                              │
                  ┌───────────▼────────────┐
                  │ 3. พระราชกฤษฎีกา (พ.ร.ฎ.)│ กฎหมายลำดับรอง (ครม. เสนอ)
                  └───────────┬────────────┘
                              │
                  ┌───────────▼────────────┐
                  │ 4. กฎกระทรวง           │ รัฐมนตรีออกตาม พ.ร.บ.
                  └───────────┬────────────┘
                              │
                  ┌───────────▼────────────┐
                  │ 5. ข้อบัญญัติท้องถิ่น   │ อบจ. อบต. เทศบาล กทม.
                  └────────────────────────┘
```
$$\text{กฎหมายใด} \land \text{ขัดแย้งกับรัฐธรรมนูญ} \implies \text{ตกเป็นโมฆะและใช้บังคับมิได้ (มาตรา 5)}$$

---

### 2. สูตรการแก้ไขเพิ่มเติมรัฐธรรมนูญ (มาตรา 255 & 256)
```
[ผู้มีสิทธิเสนอ] (ครม. / ส.ส. 100 คน / สมาชิกรัฐสภา 140 คน / ประชาชน 50,000 คน)
       │
       ▼
[วาระที่ 1: รับหลักการ] ──> ต้องได้เสียง ≥ 1/2 ของสองสภา (≥ 350 จาก 700)
                           ∧ ต้องมี ส.ว. เห็นชอบ ≥ 1/3 (≥ 67 จาก 200 ส.ว.)
       │
       ▼
[วาระที่ 2: แปรญัตติรายมาตรา] ──> ถือเสียงข้างมากธรรมดาของผู้ลงคะแนน
       │
       ▼
[ช่วงทอดเวลา] ──> ต้อง "รอไว้ 15 วัน" จึงจะเข้าสู่วาระที่ 3
       │
       ▼
[วาระที่ 3: ขั้นเห็นชอบ] ──> ล็อก 3 ชั้น (Triple Lock):
                           1. เสียงเห็นชอบเกินกึ่งหนึ่งของรัฐสภา (≥ 350)
                           2. ส.ว. เห็นชอบ ≥ 1/3 (≥ 67 คน)
                           3. ส.ส. พรรคที่ไม่มี รมต./ไม่มีประธานสภา (ฝ่ายค้าน) เห็นชอบ ≥ 20%
       │
       ▼
[ด่านประชามติบังคับ] ──> ถ้าแก้ หมวด 1, หมวด 2, หมวด 15, หรืออำนาจศาล/องค์กรอิสระ
                         ⟹ ต้องจัดให้มี "ประชามติ" ก่อนนำขึ้นทูลเกล้าฯ!
```

**ข้อห้ามเด็ดขาด (มาตรา 255):** ห้ามแก้ไขเพิ่มเติมที่มีผลเป็นการเปลี่ยนแปลงระบอบประชาธิปไตยอันมีพระมหากษัตริย์ทรงเป็นประมุข หรือเปลี่ยนแปลงรูปแบบของรัฐ (ราชอาณาจักรอันหนึ่งอันเดียว) เด็ดขาด!

### 3. สูตรตรวจสอบการออกพระราชกำหนด (พ.ร.ก. มาตรา 172)
$$\text{พ.ร.ก.} = \text{จำเป็นรีบด่วนอันมิอาจหลีกเลี่ยงได้} \land \text{เข้า 4 กรณี (มั่นคง/ปลอดภัย/เศรษฐกิจ/ภัยพิบัติ)} \land \text{เสนอสภาคราวถัดไป}$$

- **ด่านสภา:** ถ้ารัฐสภา **อนุมัติ** กลายเป็น พ.ร.บ. ถาวร / ถ้า **ไม่อนุมัติ** พ.ร.ก. เป็นอันตกไป (ไม่กระทบกิจการที่ทำไปแล้ว)
- **ด่านศาล รธน. (ม.173):** ก่อนสภาลงมติ ส.ส. หรือ ส.ว. $\ge 1/5$ เข้าชื่อส่งศาลรัฐธรรมนูญวินิจฉัยความจำเป็นรีบด่วนได้

---

### 4. ตราชั่งหลักความได้สัดส่วนในการจำกัดสิทธิ (มาตรา 26)
กฎหมายจำกัดสิทธิจะชอบด้วยรัฐธรรมนูญได้ ต้องผ่าน 4 ด่าน:
1. **มีกฎหมายแม่บทระดับ พ.ร.บ. ให้อำนาจไว้ชัดเจน**
2. **ไม่กระทบกระเทือนสาระสำคัญแห่งสิทธิ (Essential Core)**
3. **ไม่มุ่งหมายใช้บังคับแก่กรณีใดกรณีหนึ่งเป็นการเจาะจง**
4. **ผ่านการทดสอบความได้สัดส่วน (เป้าหมายชอบ $\to$ เหมาะสม $\to$ จำเป็นที่สุด $\to$ ได้สัดส่วนพอสมควรแก่เหตุ)**
